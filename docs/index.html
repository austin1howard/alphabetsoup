Design

Built for agents, not a team of humans.

Most multi-agent frameworks copy a human org: personas that chat, negotiate, and hold standups. Agents gain nothing from the ritual — it's tokens spent re-explaining what a spec already records. Coordination here is deliberately thin, and these four decisions carry it.

// protocol

Specs are the source of truth

aspen owns the specs. Engineer agents read from them and implement against them. When code and spec disagree, the agent flags the conflict instead of guessing — so intent lives in one place, not re-explained each turn.

// scope

Each agent's context is one domain

An agent loads only the domain it owns, not the whole repo. Context stays small and relevant as the project grows, which holds output quality up and token cost down.

// hand-off

Hand-offs are structured, not chat

Each turn ends with a structured Summary + Requests block. The coordination skill parses it and dispatches the requested work to the right agent — no free-form back-and-forth.

// parallel

Independent work runs concurrently

Agents in separate domains run at the same time. The one enforced ordering is spec before implementation: aspen writes the spec, then engineers build against it.

Plugins

One plugin per agent, named for its language's first letter.

gale for Go, pat for Python, randy for React — each enforces its own opinionated defaults. Install any of them with /plugin install <name>@alphabetsoup.

Install

Register the marketplace, then install the core plugin.

1
Register the marketplace in your project's .claude/settings.json. 
{
  "extraKnownMarketplaces": [{ "github": "austin1howard/alphabetsoup" }]
}
2
Install the core plugin and run configuration. 
/plugin install alphabetsoup@alphabetsoup
/alphabetsoup:configuration

Step 1 is a one-time bootstrap. From then on /alphabetsoup:configuration keeps the marketplace registered, detects your stack, and enables the right plugins.

Skills

Two slash commands drive the marketplace.

/alphabetsoup:configuration

Configuration

Detects your stack, enables the matching plugins, scaffolds the domains each agent owns, and re-registers the marketplace. Run it any time the setup drifts.

/alphabetsoup:coordination

Coordination

Takes a goal, dispatches each piece to the agent that owns the relevant domain, runs independent pieces in parallel, and routes the Summary + Requests hand-offs until the goal is done.
